## IV · Featured Projects

<details open>
<summary><b>Phantom — Autonomous AI Trading Agent</b></summary>
<br/>

Building a 6-node LangGraph agent (reason → risk → decide → narrate → remember → execute) to manage a virtual ₹1L NSE portfolio every 15 minutes during market hours, fusing pandas-ta technical signals with live news sentiment. A persistent trade-memory layer in Redis and PostgreSQL lets the agent write a thesis on every buy and reference it on exit — giving multi-session reasoning continuity most single-shot trading bots lack. Decisions stream to a Next.js dashboard over WebSocket in plain English, making agent reasoning auditable for non-technical users.

| Stack | Scale | Status | Repository |
|---|---|---|---|
| LangGraph · LangChain · FastAPI · Next.js 14 · PostgreSQL · Redis · Docker · Claude API | Runs every 15 min during market hours | Personal · 2026 – Present | [github.com/Chidhanand07/Phantom](https://github.com/Chidhanand07/Phantom) |

</details>

<details>
<summary><b>ShipIt — AI Deployment CLI</b></summary>
<br/>

A Go CLI that scans any codebase, detects its stack, and generates production-ready Dockerfiles, docker-compose, GitHub Actions CI/CD, and platform configs (Railway / Render / Fly.io) in under 60 seconds. An optional LangChain + Claude layer enriches environment-variable documentation and resolves unfamiliar stacks, while the core tool stays fully functional with zero API key required. Ships as cross-platform binaries via Homebrew tap, npx, and a curl installer, with GoReleaser automating the pipeline.

| Stack | Scale | Status | Repository |
|---|---|---|---|
| Go · Cobra · Bubble Tea · LangChain · Claude API · Docker · GoReleaser | Cross-platform (macOS/Linux/Windows, amd64+arm64) | Open Source · 2026 – Present | [github.com/Chidhanand07/ShipIt](https://github.com/Chidhanand07/ShipIt) |

</details>

<details>
<summary><b>Gambit — Production Chess Platform</b></summary>
<br/>

A real-time multiplayer chess platform architected and deployed as 3 microservices (Vercel, Railway, Render), achieving sub-100ms move propagation via Socket.io and Supabase Realtime. A Stockfish-powered accuracy rating system scores both players 0–100 after each game via async webhook, persisting results to Supabase PostgreSQL. Includes smart matchmaking and a live friends system across a Next.js frontend, Node/Express/Socket.io game server, and a Python FastAPI engine.

| Stack | Performance | Status | Repository |
|---|---|---|---|
| Next.js 14 · TypeScript · Node · Express · Socket.io · FastAPI · python-chess · Stockfish · Supabase · Vercel · Railway · Render | Sub-100ms move propagation | Full-Stack · Deployed 2025 | [github.com/Chidhanand07/GAMBIT](https://github.com/Chidhanand07/GAMBIT) |

</details>
